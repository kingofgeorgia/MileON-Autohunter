# ✅ ИСПРАВЛЕНО: Разделение Model и Trim

## 🎯 Проблема
Раньше в колонке "Модель" показывалась комплектация (Trim), а не модель автомобиля:
- Вместо модели (например "Camry") показывалось "XLE 4dr Sedan" (комплектация)
- Невозможно было увидеть настоящую модель автомобиля

## ✅ Решение

### 1. Обновлен parser.py
Теперь парсер сохраняет три отдельных поля:
```python
'model_id': i.get('model_id'),      # ID модели (например 1089)
'model': '',                         # Название модели (пока пустое)
'trim': i.get('car_model', '')      # Комплектация (например "XLE 4dr Sedan")
```

**Что изменилось:**
- `model_id` - добавлено новое поле с ID модели из API
- `trim` - комплектация перенесена из `model` в отдельное поле `trim`
- `model` - оставлено для будущего добавления названий моделей

### 2. Обновлен app.py
Добавлена новая колонка **Комплектация** после Модели:

**Структура колонок:**
```
┌─────────┬─────────────┬───────────┬─────────────────────┬──────┬─────────┐
│ Рейтинг │ Марка       │ Модель    │ Комплектация        │ Год  │ Цена    │
├─────────┼─────────────┼───────────┼─────────────────────┼──────┼─────────┤
│ 75.3    │ Toyota      │ #1089     │ XLE 4dr Sedan       │ 2019 │ $12,500 │
│ 72.1    │ BMW         │ #103      │ xDrive50i 4dr AWD   │ 2013 │ $8,300  │
│ 70.5    │ Jeep        │ #446      │ Rubicon 2dr 4x4     │ 2016 │ $19,000 │
└─────────┴─────────────┴───────────┴─────────────────────┴──────┴─────────┘
```

**Ширина колонок:**
- Модель: 80px (центр) - показывает `#model_id`
- Комплектация: 180px (влево) - показывает `trim`
