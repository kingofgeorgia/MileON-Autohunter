# Полный парсинг сайта myauto.ge

## Новая функция: "Парсить весь сайт"

В приложении добавлена новая кнопка "Парсить весь сайт", которая загружает все объявления с myauto.ge и сохраняет их в отдельный файл.

### Функции

✅ **Фоновый парсинг** - работает в отдельном потоке, не мешает основному интерфейсу
✅ **Прогресс-бар** - показывает количество загруженных объявлений в реальном времени
✅ **Таймер** - отображает прошедшее время: HH:MM:SS
✅ **Защита от блокировок** - 2-секундная пауза между запросами к серверу
✅ **Автосохранение** - результаты автоматически сохраняются в файл `full_site_YYYY_MM_DD_HH_MM_SS.json`

### Как использовать

1. Откройте вкладку "Парсер" в приложении
2. Нажмите кнопку "Парсить весь сайт"
3. Прогресс-бар начнет показывать:
   - Количество загруженных объявлений
   - Прошедшее время
4. Вы можете продолжать работать с фильтрами и таблицами - парсинг не будет мешать

### Результаты

В процессе парсинга создается файл: `full_site_YYYY_MM_DD_HH_MM_SS.json`

Примеры имен файлов:
- `full_site_2026_02_11_15_30_45.json` - парсинг начался 11.02.26 в 15:30:45
- `full_site_2026_02_12_08_15_22.json` - парсинг начался 12.02.26 в 08:15:22

### Технические детали

**Задержка между запросами**: 2 секунды
- Предотвращает блокировку IP
- Может быть изменена в коде (в методе `full_site_parse`)

**Формат файла**: JSON с полной информацией о каждом объявлении

**Статусы парсинга**:
- ✓ Завершено - показывает количество загруженных объявлений и время работы
- ✗ Ошибка - показывает описание ошибки

### Пример использования через код

```python
from mileon_saas.services.full_site_parser import FullSiteParser

# Создаем парсер с callback функцией
def my_progress(count, elapsed):
    print(f"Загружено: {count}, время: {elapsed:.1f}с")

parser = FullSiteParser(delay_seconds=2.0, progress_callback=my_progress)

# Парсим первые 10 страниц
parser.parse_all_pages(max_pages=10)

# Или все страницы
parser.parse_all_pages(max_pages=None)

# Сохраняем в файл
output = parser.save_to_file()
print(f"Сохранено в: {output}")

# Работаем с данными
print(f"Всего объявлений: {len(parser.all_listings)}")
print(f"Первое объявление: {parser.all_listings[0]}")
```

### Возможные проблемы

**Проблема**: Парсинг идет очень долго  
**Решение**: Используйте параметр `max_pages=10` для тестирования вместо полного парсинга

**Проблема**: Сайт не отвечает/блокирует  
**Решение**: Подождите несколько минут и попробуйте снова. Увеличьте `delay_seconds` в коде.

**Проблема**: IP заблокирован  
**Решение**: Подождите несколько часов или используйте VPN
