# 🔍 Обучение ML модели через мониторинг myauto.ge

## 📋 Концепция

Поскольку у вас **нет реальных закрытых сделок**, можно использовать мониторинг myauto.ge:

### Идея:
1. **Ежедневно собирать снимки** листингов
2. **Отслеживать исчезновения** — листинг пропал = вероятно продан
3. **Оценивать цену продажи** — последняя листинговая цена (с корректировкой)
4. **Создавать предполагаемые сделки** для обучения ML

### ⚠️ Ограничения:
- **Неточная цена покупки** — не знаем реальную цену, оцениваем
- **Неточная цена продажи** — листинговая ≠ реальная (обычно на 5-10% ниже)
- **Неизвестен ремонт** — предполагаем среднюю стоимость
- **Листинг мог исчезнуть не из-за продажи** — снят с продажи, авария, и т.д.

### ✅ Преимущества:
- **Быстрый старт** — не нужно ждать реальных сделок
- **Большой объем данных** — тысячи листингов ежемесячно
- **Лучше, чем ничего** — для первоначального обучения

## 🛠️ Автоматизация (daily_tracking.py)

Создайте скрипт для ежедневного запуска:

```python
# daily_tracking.py
import asyncio
import sqlite3
from datetime import datetime

from setup_listing_tracking import take_snapshot, mark_disappeared_listings
from mileon_saas.services.ingestion import fetch_and_ingest_myauto


async def daily_run():
    """Ежедневная задача мониторинга."""
    print(f"[{datetime.now()}] Начало ежедневного мониторинга")
    
    # 1. Обновить листинги из API
    print("1/3 Загрузка новых листингов...")
    await fetch_and_ingest_myauto(limit=100, skip_existing=False)
    
    # 2. Сделать снимок
    print("2/3 Создание снимка...")
    await take_snapshot()
    
    # 3. Пометить исчезнувшие
    print("3/3 Анализ исчезнувших...")
    mark_disappeared_listings()
    
    print(f"[{datetime.now()}] Мониторинг завершен")


if __name__ == "__main__":
    asyncio.run(daily_run())
```

Запуск через Task Scheduler (см. Шаг 3).

## 📞 FAQ

**Q: Сколько дней нужно мониторить?**  
A: Минимум 30 дней, рекомендуется 60-90 для статистической значимости.

**Q: Какая точность модели ожидается?**  
A: R² 0.60-0.70 на предполагаемых сделках, 0.75-0.85 на реальных.

**Q: Можно ли использовать только уверенные сделки (≥80%)?**  
A: Да, но будет меньше данных. Компромисс: ≥70% даст достаточный объем.

**Q: Как часто переобучать модель?**  
A: Каждые 1-2 месяца в начале, потом раз в квартал.

**Q: Что делать, если R² < 0.50?**  
A: Собирайте больше данных или увеличьте min_confidence до 0.8.
