## 🎯 Как использовать приложение

### Запуск

**Вариант 1 (Самый простой):**
- Двойной клик на `start.bat`

```powershell
.\start.ps1
```

```bash

```

## 📊 Интерфейс приложения

### Область фильтров
- **Модель** - фильтр по названию модели (любая часть названия)
- **Цена ($)** - диапазон цены (например 5000-15000)
- **Год** - диапазон года выпуска (например 2018-2023)
- **Рейтинг ≥** - минимальный рейтинг (50, 60, 70, 80, 90)

Все фильтры применяются **в реальном времени** при печати.

### Таблица
Показывает все найденные автомобили, отсортированные по рейтингу (лучшие первыми).

**Цвета строк:**
- 🟢 **Зеленый (70-100)** - отличное предложение
- 🟡 **Желтый (60-69)** - хорошее предложение  
- ⚪ **Белый (50-59)** - нормальное предложение

### Кнопки действий

**🔄 Обновить парсер**
- Запускает полный скан рынка (1-2 минуты)
- Скачивает свежие данные с myauto.ge
- Отправляет алерты в Telegram о новых предложениях и снижениях цен
- Обновляет таблицу

**🔄 Перезагрузить данные**
- Перезагружает данные из файла `cars_data.json`
- Не запускает парсер, только обновляет UI

**📋 Копировать ссылку**
1. Выберите автомобиль в таблице (кликните)
2. Нажмите кнопку "Копировать ссылку"
3. Ссылка будет скопирована в буфер обмена
4. Можна вставить в браузер или поделиться

**❌ Выход**
- Закрывает приложение

## 📊 Система рейтинга

Рейтинг рассчитывается на основе трех показателей:

- **💰 Цена (40%)** - низкая цена = высокий рейтинг
- **📅 Год выпуска (35%)** - более новые = выше рейтинг
- **⚙️ Объем двигателя (25%)** - больший объем = выше рейтинг

**Пример:**
- Новая Toyota 2023 за $15,000 с объемом 2500cc = 85/100 ⭐
- Старая машина 2010 за $5,000 с объемом 1600cc = 45/100

## 📱 Telegram Алерты

Парсер автоматически отправляет в Telegram:

✅ **Новое хорошее предложение** (рейтинг > 70)
- Рейтинг и основные параметры
- Фото первое изображение (если есть)
- **Кликабельная ссылка** на объявление ↗️

📉 **Снижение цены** (≥ 5%)
- Показывает старую и новую цену
- Разница в долларах и процентах
- Ссылка на объявление

## ⚙️ Настройка (для опытных пользователей)

### Изменить диапазон цены (600-50000$ по умолчанию)

В **parser.py** строка:
```python
base_url = 'https://api2.myauto.ge/en/products?vehicleType=0&ForRent=&Mans=&PriceFrom=600&PriceTo=50000&CurrencyID=1&MileageType=1&Customs=1&Page={}'
```

Измените `PriceFrom=600` и `PriceTo=50000`

### Изменить минимальный объем двигателя (500cc по умолчанию)

В **parser.py** строка:
```python
if i['engine_volume']>=500 or i['engine_volume']==0:
```

### Изменить Telegram Chat ID

В **telegram_bot.py** строка:
```python
CHAT_ID = 1639780796  # Ваш ID здесь
```

## 🐛 Проблемы и решения

### "Файл cars_data.json не найден"
→ Нажмите "Обновить парсер" один раз

### Парсер очень долго загружается
→ Это нормально, первый запуск может занять 1-2 минуты

### Таблица пуста
→ Нажмите "Перезагрузить данные"

### Telegram алерты не приходят
→ Проверьте: 
  - Интернет подключен
  - Введен правильный BOT_TOKEN в telegram_bot.py
  - Введен правильный CHAT_ID
