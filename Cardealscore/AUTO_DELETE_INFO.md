# ⚠️ КРИТИЧЕСКАЯ ИНФОРМАЦИЯ: Автоудаление myauto.ge

## 🔄 Система автоудаления

MyAuto.ge **автоматически удаляет объявления каждые ~30 дней**:

- 📅 **30 дней** (1 месяц) → Первое автоудаление
- 📅 **60 дней** (2 месяца) → Второе автоудаление  
- 📅 **90 дней** (3 месяца) → Третье автоудаление
- 📅 **120+ дней** → Последующие автоудаления

**Это НЕ означает, что авто продано!** Продавец может переразместить объявление заново.

## 📊 Обновленная система уверенности

### Факторы уверенности (confidence):

| Критерий | Изменение уверенности | Причина |
|----------|----------------------|---------|
| **АВТОУДАЛЕНИЕ** 30±3 дня | **-50%** | Системное удаление |
| **АВТОУДАЛЕНИЕ** 60±3 дня | **-50%** | Системное удаление |
| **АВТОУДАЛЕНИЕ** 90±3 дня | **-50%** | Системное удаление |
| Оптимально (14-60 дней) | +30% | Реальный срок продажи |
| Снижение цены | +20% | Активно продавали |
| Слишком быстро (<7 дней) | -20% | Подозрительно |
| Слишком долго (>120 дней) | -30% | Скорее всего сняли |

### Примеры расчета:

#### Пример 1: Автоудаление (30 дней)
```
Базовая уверенность: 50%
- Дней на рынке: 30 (оптимально) → +30%
- АВТОУДАЛЕНИЕ (30±3) → -50% ⚠️
= Итого: 30% (НИЗКАЯ уверенность)
```

#### Пример 2: Реальная продажа (42 дня)
```
Базовая уверенность: 50%
- Дней на рынке: 42 (оптимально) → +30%
- Цена снизилась на 8% → +20%
- НЕ попадает в автоудаление ✅
= Итого: 100% → max 100% (ВЫСОКАЯ уверенность)
```

#### Пример 3: Автоудаление с низкой ценой (61 день)
```
Базовая уверенность: 50%
- Дней на рынке: 61 (приемлемо) → +20%
- Цена снизилась на 12% → +20%
- АВТОУДАЛЕНИЕ (60±3) → -50% ⚠️
= Итого: 40% (НИЗКАЯ уверенность)
```

## 🛠️ Как система определяет автоудаление

### Код (setup_listing_tracking.py):
```python
# Периоды автоудаления myauto.ge
auto_delete_periods = [30, 60, 90, 120, 150, 180]
tolerance = 3  # ±3 дня допуск

for period in auto_delete_periods:
    if abs(days_on_market - period) <= tolerance:
        # Вероятно автоудаление системой
        confidence -= 0.5  # -50% уверенности
        break
```

### Логика:
- Вычисляется **days_on_market** = время от `listing_date` до последнего снимка
- Если попадает в диапазон **27-33, 57-63, 87-93** дней и т.д.
- **Уверенность снижается на 50%** (с возможным итогом 0-20%)

## 🔍 Ручная проверка (опционально)

### SQL запрос для анализа:
```sql
-- Распределение исчезнувших по дням
SELECT 
    days_listed,
    COUNT(*) as count,
    AVG(confidence_score) as avg_confidence,
    CASE 
        WHEN days_listed BETWEEN 27 AND 33 THEN 'Автоудаление 30'
        WHEN days_listed BETWEEN 57 AND 63 THEN 'Автоудаление 60'
        WHEN days_listed BETWEEN 87 AND 93 THEN 'Автоудаление 90'
        ELSE 'Реальная продажа?'
    END as category
FROM estimated_deals
GROUP BY days_listed
ORDER BY days_listed;
```
