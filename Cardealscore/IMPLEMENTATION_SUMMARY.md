Все фильтры работают **в реальном времени** (применяются при печати):
- Модель: содержит текст (case-insensitive)
- Цена: от-до диапазон

| ❌ Выход | Закрывает приложение |

## 🔗 Примеры сгенерированных URL

### Для Toyota Camry (ID: 120480398)
```
https://myauto.ge/en/pr/120480398/for-sell-cars-xle-4dr-sedan-automatic-2015-cng-gori?offerType=vipPlus&source=search
```

### Для Jeep (ID: 120457772)
```
https://myauto.ge/en/pr/120457772/for-sell-cars-2025-diesel-batumi?offerType=vipPlus&source=search
```

**Компоненты URL:**
- `/pr/` - тип объявления (вместо `/cars/`)
- `{car_id}` - ID автомобиля
- `for-sell-cars` - тип продажи
- `{model}` - модель авто
- `{year}` - год выпуска
- `{fuel_type}` - тип топлива (petrol, diesel, hybrid и т.д.)
- `{location}` - локация (tbilisi, gori, batumi и т.д.)
- `?offerType=vipPlus&source=search` - query параметры
