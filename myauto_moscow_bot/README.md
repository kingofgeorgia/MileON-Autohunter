# Telegram-бот для расчёта стоимости авто с myauto.ge до Москвы

Бот принимает ID объявления myauto.ge или полную ссылку, получает данные объявления через JSON API myauto.ge и извлекает основные параметры автомобиля и считает:

- цену автомобиля;
- курс валют;
- таможенную пошлину для физлица;
- таможенный сбор;
- утильсбор;
- логистику и прочие расходы до Москвы;
- итоговую сумму.

## Что уже умеет

- принимает ID myauto.ge или URL;
- получает цену, год, объём двигателя, мощность, пробег и VIN из JSON API с fallback-логикой по полям;
- считает таможню по ставкам для физлица;
- считает льготный утильсбор и приближённый утиль для мощных авто;
- все настраиваемые расходы вынесены в `config.yaml`.

## Важное ограничение

Для автомобилей мощнее 160 л.с. таблицы утильсбора после реформ 2025/2026 стали заметно сложнее. В проекте уже заложена приближённая таблица для практического MVP, но её нужно один раз сверить по вашим контрольным кейсам (например, через Альту или по фактическим расчётам брокера) и при необходимости подправить в `config.yaml`.

## Запуск

```bash
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Откройте `.env` и вставьте токен Telegram-бота.

Затем запустите:

```bash
python bot.py
```

## Пример использования

Пользователь отправляет:

```text
120842595
```

или

```text
https://myauto.ge/en/pr/120842595/for-sell-cars-sedan-volkswagen-jetta-2021-petrol-caucasus-auto-market
```

Бот отвечает подробной раскладкой с итоговой стоимостью до Москвы.

## Где править реальные бизнес-расходы

Файл `config.yaml`:

- `route.fixed_costs_rub` — все фиксированные расходы до Москвы;
- `route.purchase_commission_percent` — комиссия на выкуп, если нужна;
- `util_fee_personal_2026.high_power_bands_approx_rub` — таблица для мощных машин;
- `default_purchase_currency` — дефолтная валюта, если myauto не отдал символ явно.
