# MileON Autohunter Migration Workspace

Это основная папка для переноса проекта на новую архитектуру backend/frontend.

Назначение:
- хранить промежуточную версию переноса без разрушения старых частей проекта;
- собирать новый backend и frontend в одном рабочем контуре;
- постепенно переносить логику расчётов, UI и интеграции.

Структура:
- backend/ — новый backend API
- frontend/ — новое веб-приложение или веб-страница для UI
- shared/ — общие модели и правила расчётов
- docs/ — план, заметки и спецификации

Важно:
- старые части проекта остаются нетронутыми;
- здесь будет вестись основная разработка нового направления.
